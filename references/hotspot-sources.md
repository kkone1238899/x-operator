# Hotspot sources & selection method

How to find what's hot and how to decide what's worth covering. Two inputs fused 2026-10-07:
AIHOT's selection methodology (KKKKhazix/AIHOT, MIT) and the 4-site hotspot stack
popularized by @Jason23818126's viral post (Sep 2026, 62K views).

## Selection method (from AIHOT's docs/selection.md)

### 1. Prefilter — is this our industry?

BLOCK / PASS / UNKNOWN. Block the obviously off-niche (politics red line goes here: BLOCK). PASS and UNKNOWN move on.

### 2. Score TWICE, independently, same rubric

One scoring pass has position bias and mood bias. Run the same 10-point rubric twice (fresh eyes: second pass without looking at the first score), take the average. A topic that scores ≥7 twice is real; one that swings wildly is noise — drop it or re-examine.

### 3. Source tiers — different bars

- **T1 (first-party)**: official announcements, original launches, the builder's own post. Lower bar — first-hand is worth covering even at modest heat.
- **T2 (media/personal)**: commentary, reposts, hot takes. Higher bar — must earn its place with heat or insight.

Same story from T1 + T2s = strong signal. T2-only chatter needs real heat.

### 4. Cluster into EVENTS, rank heat by event

Multiple sources reporting the same thing = ONE event. Heat = number of **independent** sources in the last 48h (one outlet posting 10 times counts once; 24h half-life). Rank events, not posts.

For topic curation this means: don't queue 3 topics that are the same story. Queue the event once, pick the sharpest angle.

### 5. Calibrate from your own mistakes

Keep a labeled set of past topics: "picked right / picked wrong" (your daily review already produces this). When a type keeps mis-scoring, fix the rubric wording for that type first — moving the threshold only shifts everything.

## What this changes for us

- Topic queue entries get: two scores (avg), source tier, event id (same story = same id).
- A "hotspot" for engagement = an event with ≥3 independent sources in 24h, or a T1 first-party post with early traction.
- The radar skill scans these 4 sites + the money-blogger watch list, and clusters before filing.
