# Scoring rubrics

## Topic score (10 points, ≥7 to queue)

| Dimension | Max | Guide |
|---|---|---|
| Trend / heat | 4 | 4 = everyone's discussing it right now; 2 = warm niche topic; 0 = nobody cares yet |
| Controversy | 2 | 2 = splits opinions, invites debate; 1 = mild disagreement; 0 = nobody would argue |
| Value density | 3 | 3 = reader walks away with something usable; 1 = interesting but thin; 0 = pure noise |
| Account fit | 1 | 1 = on-IP; 0 = off-brand (then it's disqualified regardless of total) |

**Calibration**: a 7 means "I would stop scrolling for this." When in doubt, score down — the queue must stay hungry.

## Critic self-score (per post, 0–10 each, average ≥7)

| Dimension | What to judge |
|---|---|
| Hook strength | Does the first line stop the scroll alone? |
| Information density | Is every sentence earning its place? |
| Readability | Can it be read in one breath? Any friction? |
| Credibility | Are claims sourced or first-hand? Any hand-waving? |
| Account fit | Does it ladder up to the IP? |

Average below 7 → one rewrite, then ship the better version. The rewrite must change the weakest dimension, not just rephrase.
