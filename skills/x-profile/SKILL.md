# x-profile

Traffic is worthless if the profile doesn't convert the click. Fix the profile before chasing reach.

## Inputs

- `config`: positioning, proof points, content pillars (`config/config.yaml`)
- `references`: 5–10 bios from strong accounts in the same niche (read them live)

## Procedure

### 1. The 3-second test

Open the profile as a stranger. Within 3 seconds it must answer: **who is this** and **why should I follow**. If not, rewrite.

### 2. Study the niche

Read 5–10 bios from accounts the target audience already follows. Extract patterns: how they open, length, how they convey credibility without sounding like an ad, line breaks, tone. Model the rewrite on what works *in this niche* — not generic marketing copy.

### 3. Rewrite formula

```
Help [audience] get [outcome]. [Proof]. Posting [topics] [cadence].
```

- Concrete and differentiated — it should be impossible to swap in a competitor's name.
- Match the account's real voice (see `references/human-voice.md`).
- Offer 2–3 variants.

### 4. Supporting surfaces

- **Pinned post**: states the IP in one post — the best on-brand post so far, or a short intro.
- **Avatar/header**: must read as a real human at thumbnail size.
- Re-audit monthly or after any positioning change.

## Output

Bio variants + pinned-post recommendation + the 3-second-test verdict.

## Failure modes

| Symptom | Cause | Fix |
|---|---|---|
| Clicks but no follows | Bio is vague or marketing-flavored | Rewrite from niche references, concrete proof |
| Bio promises what posts don't deliver | Positioning drift | Align bio with the actual content pillars |
